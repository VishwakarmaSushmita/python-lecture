Features of Python
	
1. General-purpose programming language
	Python can be used to develop many different types of applications, such as websites, desktop software, automation scripts, games, data analysis, and AI applications. It is not limited to one particular task.
	
2. High-level language
	Python is a high-level programming language, meaning its syntax is closer to human language and easier to understand than low-level languages such as Assembly. The programmer does not need to manage hardware details like memory addresses directly.
	
3. Open-Source
	Python is open-source, so its source code is freely available. Anyone can use Python, study how it works, modify it, and contribute to its development.
	
4. Cross-platform compatible
	Python programs can run on different operating systems, such as Windows, macOS, and Linux, usually without changing the program significantly.
	
5. Cross-language integration
	Python can work together with programs and libraries written in other programming languages such as C, C++, Java, and .NET. This allows developers to use Python along with other technologies when needed.
	
6. Portable
	Python programs are generally portable, meaning the same Python code can be moved from one computer or operating system to another with little or no modification, provided the required Python environment and libraries are available.
	
7. Interpreted language
	Python code is executed by the Python interpreter rather than being compiled directly into machine code in the traditional way first. This makes testing and running programs convenient and supports interactive programming.
	
8. Object-Oriented
	Python supports object-oriented programming (OOP). Programs can be organized using classes and objects, which helps developers structure large and complex applications.
	
9. Provides built-in data structures
	Python provides useful data structures such as lists, tuples, sets, and dictionaries. These make it easier to store, organize, and manipulate data.
	
10. Dynamically Typed
	In Python, you don't have to specify a variable's data type when declaring it. Python determines the type automatically at runtime.
